Гейтвей прогнозов — API

Описание отдаётся тем же процессом, что и данные. Страница работает без интернета: внешних адресов здесь нет ни одного, спецификация забирается с этого же хоста.

Лента GET /ws/stream в списке есть, но через эту страницу не проверяется: это WebSocket, а не HTTP-запрос. Проверить его можно из консоли браузера: 

const ws = new WebSocket(`ws://${location.host}/ws/stream`);
ws.onmessage = (e) => console.log(JSON.parse(e.data));

Запросы со страницы уходят тому гейтвею, что указан в поле адреса. Не вставляйте туда адрес, который недоверенный: он получит все ответы, а в режиме записи ещё и тело.
